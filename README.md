# 💒 전국 웨딩홀 가격 지도 (Wedding Map)

결혼식장이 **방문 상담으로만 알려주는 식대·대관료**를 모아, 전국 1,100여 식장을
**지도 위에서 위치·가격으로 한눈에** 비교하는 사이트입니다.

> 🌐 라이브: **https://ikdd7.github.io/test5/** (→ 지도)
> 핵심 페이지: `map.html`(메인 지도) · `wedding.html`(데이터·통계) · `method.html`(방법론)

---

## ✨ 무엇을 하나
- 🗺️ **전국 식장 지도** — 카카오 지도 위에 식장을 핀으로 표시. **가격대별 색상**(저렴 초록↔비쌈 빨강), 가격 미확인은 회색
- 🔎 **필터** — 홀타입 · 시간대 · 💰가격있는 곳만 · ✅검증만 · 💗찜
- 💗 **찜·비교 패널** — 마음에 든 식장을 찜 → **하객수 기준 예상 총비용**으로 정렬 비교 → 메모 → 카톡 공유
- 📍 **클릭 팝업** — 식장명·지역·식대·대관료·대표사진·다중소스 평균 표기
- 📄 **지역 SEO 페이지** — "지역 웨딩홀 식대 중앙값"을 정적 HTML로(데이터 3곳↑ 지역 자동 생성)

## 🧱 데이터가 만들어지는 방식
| 단계 | 도구 | 비고 |
|---|---|---|
| 식장 이름·좌표 수확 | `harvest.js` (카카오 장소검색) | 전국 시군구 순회 → 1,100여 곳 |
| 좌표 정밀화 | `geocode.js` (카카오) | 주소→정확 좌표 |
| 중복 병합 | `dedupe.js` | 같은 식장 다른 홀 합침 + 잡음 제거 |
| 가격 수집 | `scrape-smartwedding.js` | 공개 가격정보 사이트 렌더·파싱 |
| 가격 병합 | `pricemerge.js` | **다른 소스면 평균**, 같은 소스는 스킵 |

> ⚠️ **이름·좌표는 자동 수집 가능하지만, 가격은 공개 API가 없어** 일부 공개 가격사이트(smartwedding 등)에서만 모읍니다. 나머지는 **제보(크라우드소싱)** 로 채우는 구조.

## 🤖 자동화 (GitHub Actions — 폰에서 Run)
`.github/workflows/` 의 워크플로를 Actions 탭에서 **Run** 하면 데이터가 갱신·자동 커밋됩니다.
- `harvest.yml` — 전국 식장 수확 (카카오 키 필요: secret `KAKAO_REST_KEY`)
- `geocode.yml` — 좌표 정밀화
- `scrape.yml` — smartwedding 가격 수집
- `scrape-iwedding.yml` — iwedding 가격 수집
- (`scrape-direct.yml` — directwedding은 현재 로그인 벽으로 보류)

## 🗂️ 주요 파일
```
map.html / map.js   ← 메인 지도(카카오 SDK, 클러스터·필터·찜·비교·팝업)
venues.js           ← 전국 식장 데이터(이름·좌표·가격·사진·출처)  ※스크립트가 생성
stats.js            ← 강건 통계(중앙값·이상치제외·백분위·소스평균)
regions.js / koreamap.js ← 지역 슬러그 / 폴백 히트맵
wedding.html        ← 데이터·통계 대시보드(히트맵·차트·제보)
region/*.html       ← 지역 SEO 랜딩(build.js가 생성)
build.js            ← 지역 페이지 + sitemap 생성
method.html         ← 방법론·신뢰·면책
seed.html / studio.html ← 운영자: 수기 입력 / SNS 카드
test.js             ← 자동 검증 6,400+건 (통계·데이터·페이지 구조)
```
> 계산 엔진 `calc.js`(연봉/실업급여 등)와 그 테스트는 초기 잔재로 보존만 됨(페이지는 제거).

## 🔧 로컬에서
```bash
node test.js        # 전체 검증
node build.js       # 지역 페이지·sitemap 재생성
python3 -m http.server   # http://localhost:8000/map.html
```

## 🛡️ 데이터 품질 & 신뢰
- 가격은 **평균이 아닌 중앙값 + IQR 이상치 제외**로 가짜 1건에 안 흔들림
- 같은 식장 여러 소스 → **평균**(소스 수 표기), 미검증/추정은 명시
- 자세한 수집·검증·면책: `method.html`, `WEDDING_SETUP.md`, `LEGAL_NOTES.md`
