# 보청기 지원금·실부담금 진단기

보청기 시장의 핵심 깜깜이 두 가지 — **① 정부지원금 받으면 실제 얼마 내는지**,
**② 받은 견적이 비싼지** — 를 1분 만에 풀어주는 무료 진단 도구.
기존 보청기 비교 사이트는 광고(입점)모델이라 못 건드리는 영역을 노린다.

## 왜 이 컨셉인가
- 보청기는 의료기기 **판매**라 심평원 비급여 가격공개 대상이 **아님** → 공개 가격 골조가 없어
  raw 가격 비교를 누구도 commodity로 못 만든다(= 깜깜이가 진짜).
- 진짜 어려운 건 **정부지원금 구조**(일반 117.9만 / 차상위·수급 131만, 5년 1회, 편측).
  센터는 이 혼란을 마진에 숨긴다 → 정확한 계산기 자체가 무기.
- 지원금 로직은 공식 수치라 **데이터 0건이어도 즉시 쓸모** → 콜드스타트 골조 역할.

## 콜드스타트(첫 제보 모으기)
1. **0단계 골조**: 지원금 계산(정확) + 등급별 시중가 범위(seed) → 빈 화면이 아님.
2. **역바이럴 훅**: "나 호구임?" + "지원금 얼마?" 두 동기로 견적 입력 유도, 결과 카드 공유.
3. **give-to-get**: 견적/결제 내역 1건 제보 → 동네 실결제가 전체 열람(구글폼 연동).
4. **밀도**: 한 지역부터 포화시킨 뒤 확장.
5. **마중물**: 견적서 사진 인증 제보 → 기프티콘(허위 차단 겸용).

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 진단기 화면 |
| `subsidy.js` | 지원금·실부담·견적진단 계산 엔진(페이지/테스트 공유) |
| `app.js` | UI 로직, 결과 렌더, 공유 카드, 제보 버튼 |
| `style.css` | 스타일(의존성 0) |
| `test.js` | 계산 로직 검증 — `node test.js` |

## 운영자 설정
- **제보 폼 연결**: `app.js`의 `REPORT_FORM_URL`에 구글폼 주소를 넣으면
  "내 견적 공유하기" 버튼이 폼으로 연결된다. 폼 응답 시트가 실결제가 데이터가 된다.
- **지원금 수치 갱신**: 제도가 바뀌면 `subsidy.js`의 `SUBSIDY` 상수만 고치면 전체 반영.
- **시중가 범위 보정**: 제보가 쌓이면 `subsidy.js`의 `GRADES` min/max를 실데이터로 교체.

## 실행
빌드 불필요. `index.html`을 브라우저로 열면 동작.
로직 검증은 `node test.js`.

## 면책
지원금 수치는 2026년 건강보험 보장구(보청기) 급여 기준이며 개인 자격에 따라
실제 금액은 다를 수 있다. 최종 금액은 국민건강보험공단/등록 보청기판매업소에서 확인.
