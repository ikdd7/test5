# 💰 연봉 실수령액 계산기 2026 — 수익형 웹도구

프롬프트 팩처럼 누구나 복제하는 정보 상품이 아니라, **정확한 계산 로직이 박힌 진짜 웹도구**입니다.
"연봉 실수령액 계산기"는 한국에서 매년 반복되는 거대 검색 수요(월 수십만 회)를 가진 키워드라,
한 번 만들어 검색 상위에 올리면 트래픽이 복리로 쌓이고 **광고·제휴로 자동 수익**이 발생합니다.

> 해자(moat) = ① 정확한 4대보험·세금 로직 ② 검색 트래픽 복리 ③ 작동하는 실제 앱

---

## 📂 구성

```
index.html   ← 계산기 사이트 (연봉 실수령액 / 퇴직금 / 시급·주휴수당 3-in-1)
calc.js      ← 계산 엔진. 페이지와 테스트가 같은 코드를 사용 (정확성 보장)
test.js      ← 자동 검증 2,000+건 (불변식·정합성·경계·레퍼런스 + HTML 구조)
```

## 🧮 들어있는 계산기
- **연봉 실수령액** — 국민연금·건강·장기요양·고용보험 + 근로소득세·지방세 자동 반영, 부양가족/자녀/비과세 옵션
- **퇴직금** — 입·퇴사일과 평균임금으로 즉시 계산
- **시급·주휴수당** — 주휴 포함 월 환산 + 최저임금 미달 경고

## ✅ 당신이 할 일 (약 20분, 그다음은 자동)

### 1) 인터넷에 올리기 (10분)
- **Netlify Drop:** [app.netlify.com/drop](https://app.netlify.com/drop) 에 `index.html`+`calc.js` 두 파일을 함께 드래그앤드롭 → 즉시 공개
- **GitHub Pages:** 저장소 → Settings → Pages → `main` `/(root)` → 1~2분 뒤 공개

### 2) 수익 붙이기 — `index.html` 상단 설정 두 곳 (5분)
```js
const ADSENSE_CLIENT = "";        // ① 애드센스 승인 후 ca-pub-xxxx 입력 → 광고 자동 노출
const AFFILIATE = {
  loan: { label: "...", url: "#" }, // ② 대출/카드 비교 제휴 링크 → 클릭·가입당 수익
  card: { label: "...", url: "#" },
};
```
- 애드센스: [구글 애드센스](https://adsense.google.com) 가입 → 사이트 등록 → 승인(보통 며칠) → client ID 입력
- 제휴: 대출/카드 비교 제휴 프로그램 가입 후 링크를 `url`에 입력 (실수령액 도구와 궁합 최고)

### 3) 트래픽 유입 (지속)
- [구글 서치콘솔](https://search.google.com/search-console)에 사이트 등록 → 색인 요청
- `index.html`의 `<link rel="canonical">` 의 example.com 을 실제 주소로 교체
- 블로그/커뮤니티에 "2026 연봉 실수령액 계산기" 키워드로 공유
