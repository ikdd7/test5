# 🚀 바이브코딩 마스터 키트 — 수익형 랜딩페이지

코딩을 몰라도 AI로 결과물을 만드는 **디지털 상품**과, 그것을 파는 **전환 최적화 랜딩페이지**가 모두 들어있는 즉시 판매 패키지입니다.

> 마진 100%, 재고·배송 없음. 한 번 만들면 무한 판매.

---

## 📂 구성

```
index.html        ← 판매 랜딩페이지 (이게 손님이 보는 페이지)
verify.py         ← 자동 검증 스크립트 (48개 항목 점검)
product/          ← 실제로 판매할 상품 콘텐츠 (Gumroad에 업로드)
  ├ 00-여기서-시작하세요.md
  ├ 01-바이브코딩-완전정복-가이드.md
  ├ 02-실전-프롬프트-팩-100.md
  ├ 03-30분-첫-수익-체크리스트.md
  └ 04-자주막히는-문제-해결집.md
```

---

## ✅ 당신이 할 일은 딱 3가지 (약 25분)

### 1) Gumroad에 상품 올리기 (10분)
1. [gumroad.com](https://gumroad.com) 가입 → **New product → Digital product**
2. 이름: `바이브코딩 마스터 키트`, 가격: `₩19,000` (자유롭게)
3. `product/` 폴더의 파일 5개를 **zip으로 묶어** 업로드
4. **Publish** → 상품 주소 복사 (예: `https://내아이디.gumroad.com/l/vibekit`)

### 2) 링크 한 줄 붙여넣기 (1분)
`index.html` 파일을 열어 **맨 위쪽** 이 부분을 찾으세요:

```js
const GUMROAD_URL = "#";   // ← 여기에 당신의 Gumroad 링크를 넣으세요
```

`"#"` 자리에 복사한 주소를 넣고 저장하면, 페이지의 **모든 구매 버튼**에 자동 연결됩니다.
```js
const GUMROAD_URL = "https://내아이디.gumroad.com/l/vibekit";
```

### 3) 페이지 인터넷에 올리기 (10분)
가장 쉬운 방법 (택1):

- **Netlify Drop:** [app.netlify.com/drop](https://app.netlify.com/drop) 에 `index.html`을 **드래그앤드롭** → 즉시 공개 주소 생성
- **GitHub Pages:** 이 저장소 → Settings → Pages → Branch를 `main` `/(root)` 로 Save → 1~2분 뒤 `https://[아이디].github.io/[저장소]/` 공개

끝입니다. 이제 그 주소를 SNS·커뮤니티에 공유하면 판매가 시작됩니다.

## 🔍 검증 (직접 확인하고 싶을 때)

```bash
python3 verify.py
```

페이지 구조·SEO·반응형·구매버튼 연결(220회 시뮬레이션)·상품 파일까지 **48개 항목**을 자동 점검합니다. `❌ 실패: 0` 이면 배포 준비 완료입니다.
