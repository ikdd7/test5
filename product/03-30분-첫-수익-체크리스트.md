## 🎯 오늘의 목표
인터넷에 올라간 **판매 페이지 1개** + **결제 가능한 상품 1개**.

---

### ☑️ 1단계 — 결제 받을 준비 (10분)
- [ ] [gumroad.com](https://gumroad.com) 가입
- [ ] "New product" → **Digital product** 선택
- [ ] 상품 이름 입력 (예: "바이브코딩 마스터 키트")
- [ ] 가격 설정 (추천: 첫 출시 ₩9,900~19,000)
- [ ] 판매할 파일 업로드 (이 키트 파일들을 zip으로 묶어 올려도 됨)
- [ ] **Publish** 누르고 → 상품 URL 복사 (예: `https://내아이디.gumroad.com/l/키트`)

### ☑️ 2단계 — 판매 페이지에 링크 연결 (5분)
- [ ] 이 프로젝트의 `index.html` 열기
- [ ] 맨 위 `const GUMROAD_URL = "..."` 부분에 복사한 URL 붙여넣기
- [ ] 저장

### ☑️ 3단계 — 페이지 인터넷에 올리기 (10분)
- [ ] GitHub에 저장소 만들고 `index.html` 업로드 (또는 Vercel/Netlify에 드래그앤드롭)
- [ ] Settings → Pages → main 브랜치로 배포
- [ ] 1~2분 뒤 공개된 주소 접속해서 확인 ✅

### ☑️ 4단계 — 첫 방문자 데려오기 (5분)
- [ ] 페이지 주소를 본인 SNS / 관심 커뮤니티 / 단톡방에 공유
- [ ] "AI로 앱 만드는 키트 만들었어요 👀" 한 줄 + 링크
