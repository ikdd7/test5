# 실전 프롬프트 팩 100

> 복사 → 붙여넣기 → `[ ]` 안만 수정. 검증된 프롬프트 모음.

사용법: 아래 프롬프트를 AI(Claude/ChatGPT/Cursor)에 그대로 붙여넣고, 대괄호 `[ ]` 부분만 당신 상황에 맞게 바꾸세요.

---

## A. 만들기 (Build) — 1~25

**1. 단일 HTML 앱 마스터 프롬프트**
```
너는 시니어 프론트엔드 개발자야. 외부 라이브러리 없이 순수 HTML/CSS/JS로
[기능 설명]을 하는 완성된 단일 index.html을 만들어줘. 모바일 우선, 모던 미니멀
디자인. 브라우저에서 바로 열면 작동해야 하고, 코드는 전체를 한 번에 줘.
```

**2. 랜딩페이지 생성**
```
[상품/서비스 이름]을 파는 전환 최적화 랜딩페이지를 단일 HTML로 만들어줘.
구성: 히어로(강력한 헤드라인+CTA), 문제 제기, 해결책, 혜택 3가지, 가격,
후기 자리, FAQ, 환불보장, 마지막 CTA. 톤은 [신뢰감 있고 설득력 있게].
```

**3. 계산기/변환기**
```
[입력값]을 넣으면 [결과]를 계산해 보여주는 웹 도구를 만들어줘.
실시간으로 결과가 갱신되고, 결과는 크고 명확하게.
```

**4. 폼 + 결과 페이지**
```
사용자가 [입력 항목들]을 입력하는 폼을 만들고, 제출하면 [결과물]을
보여주는 페이지를 만들어줘. 입력값 검증도 넣어줘.
```

**5. 데이터 시각화**
```
[데이터 종류]를 입력하면 차트로 보여주는 페이지를 만들어줘.
가능하면 외부 라이브러리 없이 SVG/Canvas로.
```

**6. To-do / 기록 앱**
```
브라우저 localStorage에 저장되는 [할 일 / 가계부 / 습관] 기록 앱을 만들어줘.
새로고침해도 데이터가 유지되고, 항목 추가·삭제·완료 표시 가능하게.
```

**7. 랜덤 생성기**
```
버튼을 누르면 [랜덤 결과물]을 생성하는 재미있는 페이지를 만들어줘.
공유하고 싶게 결과를 예쁜 카드 형태로.
```

**8. 타이머/카운트다운**
```
[목표 날짜/시간]까지 남은 시간을 보여주는 카운트다운 페이지를 만들어줘.
```

**9. 퀴즈/진단 테스트**
```
[주제] 관련 질문 [N]개에 답하면 결과 유형을 알려주는 진단 테스트를 만들어줘.
각 결과 유형에 설명과 추천을 붙여줘. (MBTI 스타일)
```

**10. 갤러리/포트폴리오**
```
내 [작업물/사진]을 보여주는 반응형 그리드 갤러리 페이지를 만들어줘.
클릭하면 크게 보이는 라이트박스 기능 포함.
```

**11~25. 변형 요청**
- "위 결과에 다크모드 토글을 추가해줘."
- "모바일에서 폰트가 너무 작아. 반응형으로 키워줘."
- "로딩 애니메이션을 넣어줘."
- "이 페이지에 카카오톡 공유 버튼을 추가해줘."
- "결과를 이미지로 저장하는 기능을 추가해줘."
- "입력값을 URL에 저장해서 공유하면 같은 결과가 나오게 해줘."
- "접근성(스크린리더)을 개선해줘."
- "SEO 메타태그를 추가해줘."
- "파비콘과 OG 이미지 태그를 넣어줘."
- "전체를 더 빠르게 로딩되도록 최적화해줘."
- "이 코드를 React 컴포넌트로 바꿔줘."
- "TypeScript로 다시 써줘."
- "테스트 코드를 추가해줘."
- "주석을 한국어로 친절하게 달아줘."
- "초보자가 이해할 수 있게 코드를 단순화해줘."

## B. 고치기 (Debug) — 26~50

**26. 에러 해결 (만능)**
```
이 코드를 실행하니 다음 에러가 났어:
[에러 메시지 전문]
원인을 쉽게 설명하고, 수정된 전체 코드를 줘.
```

**27. 작동 안 함**
```
[기능]이 작동해야 하는데 안 돼. 버튼을 눌러도 아무 일이 안 일어나.
원인 후보 3가지를 짚고, 가장 가능성 높은 것부터 고쳐줘.
```

**28. 화면 깨짐**
```
[설명]처럼 화면이 깨져 보여. 어떻게 보여야 하는지: [원하는 모습].
CSS를 점검하고 고쳐줘.
```

**29~50. 자주 쓰는 디버그 요청**
- "이 부분이 왜 이렇게 동작하는지 한 줄씩 설명해줘."
- "이 코드에 숨은 버그가 있어? 있다면 다 찾아줘."
- "모바일에서만 깨져. 모바일 기준으로 고쳐줘."
- "사파리/크롬에서 다르게 보여. 호환되게 해줘."
- "느려. 성능 병목을 찾아 최적화해줘."
- "콘솔에 경고가 떠. 다 없애줘."
- "이 함수가 가끔 틀린 값을 줘. 엣지케이스를 점검해줘."
- "이 코드 보안상 위험한 부분 있어?"
- "사용자가 이상한 값을 넣어도 안 깨지게 방어 코드를 넣어줘."
- "메모리 누수 가능성 있어?"
- (그 외 상황별 변형 12개 — 위 패턴을 응용)

## C. 다듬기 (Polish) — 51~70

- "이 페이지를 더 프리미엄하고 고급스럽게 디자인해줘."
- "색 조합을 추천하고 적용해줘. 브랜드 느낌은 [신뢰/활기/차분]."
- "여백과 정렬을 다듬어 전문가가 만든 것처럼."
- "마이크로 인터랙션(호버, 클릭 효과)을 자연스럽게 넣어줘."
- "타이포그래피를 개선해줘. 제목과 본문 위계를 명확히."
- "이 카피(문구)를 더 설득력 있게 다시 써줘."
- "헤드라인 후보를 10개 뽑아줘."
- "CTA 버튼 문구를 전환율 높게 3개 제안해줘."
- "이 섹션 순서가 전환에 최적인지 점검하고 재배치해줘."
- (그 외 디자인/카피 변형 11개)

## D. 팔기 (Sell) — 71~90

- "이 상품의 핵심 가치를 한 문장으로 정리해줘."
- "타깃 고객의 가장 큰 고통(pain point) 5가지를 뽑아줘."
- "그 고통을 자극하는 헤드라인을 써줘."
- "가격을 [N]원으로 할 때 정당화하는 가치 제안을 써줘."
- "FAQ 10개를 고객 입장에서 작성해줘."
- "환불 보장 문구를 신뢰감 있게 써줘."
- "후기(사회적 증거) 예시 5개를 현실적으로 작성해줘. (실제 후기 받기 전 자리표시용)"
- "출시 알림 트윗/스레드를 써줘."
- "이 상품을 소개하는 인스타 캡션 3개를 써줘."
- "이메일 대기자에게 보낼 출시 안내 메일을 써줘."
- (그 외 마케팅 카피 변형 10개)

## E. 자동화 (Automate) — 91~100

- "[반복 업무]를 자동화하는 스크립트를 만들어줘. 무엇이 필요한지 먼저 물어봐."
- "이 엑셀/CSV 데이터를 [원하는 형태]로 변환하는 도구를 만들어줘."
- "여러 파일 이름을 [규칙]대로 한 번에 바꾸는 방법을 알려줘."
- "[웹사이트]에서 [정보]를 정리하는 방법을 알려줘."
- "정해진 시간에 [작업]을 실행하는 방법을 알려줘."
- "이 작업을 노코드 도구로 자동화한다면 어떤 조합이 좋아?"
- (그 외 자동화 시나리오 4개)
