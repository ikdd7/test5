# 바이브코딩 완전정복 가이드

> 비개발자가 AI와 대화만으로 작동하는 소프트웨어를 만드는 전 과정

---

## 0장. 바이브코딩이란 무엇인가

**바이브코딩(Vibe Coding)** 은 코드를 직접 타이핑하는 대신, AI에게 **자연어로 원하는 것을 설명하면 AI가 코드를 써주는** 새로운 개발 방식입니다.

핵심은 이것입니다:
- ❌ "for문이 뭐지, 변수가 뭐지"를 외우는 게 아니라
- ✅ "이런 기능이 필요해"를 **명확하게 설명하는 능력**

이 가이드는 후자에 100% 집중합니다.

### 당신이 7일 안에 만들 수 있는 것
- 개인 랜딩페이지 / 포트폴리오
- 간단한 SaaS 도구 (계산기, 변환기, 생성기 등)
- 자동화 스크립트 (반복 업무 제거)
- 디지털 상품 판매 페이지 (이 키트가 팔리는 그 페이지처럼!)

## 2장. 바이브코딩의 황금 법칙 5가지

대부분의 사람이 AI 코딩에서 실패하는 이유는 도구가 아니라 **요청하는 방식** 때문입니다.

### 법칙 1. 결과를 먼저, 방법은 나중에
- ❌ "자바스크립트 함수 만들어줘"
- ✅ "사용자가 생년월일을 입력하면 만 나이를 계산해서 큰 글씨로 보여주는 웹페이지를 만들어줘. 모바일에서도 예쁘게."

### 법칙 2. 맥락을 통째로 준다
AI는 당신 머릿속을 모릅니다. 다음을 항상 포함하세요:
- **누가** 쓰는가 (대상 사용자)
- **무엇을** 하고 싶은가 (기능)
- **어떻게** 보였으면 하는가 (디자인/톤)
- **제약** (무료로, 백엔드 없이, 모바일 우선 등)

### 법칙 3. 한 번에 하나씩
거대한 요청 1개보다, 작은 요청 10개가 성공률이 훨씬 높습니다.
"전체 쇼핑몰 만들어줘" ❌ → "상품 목록 페이지부터 만들어줘" ✅

### 법칙 4. 에러는 그대로 복붙한다
에러가 나면 당황하지 말고, **에러 메시지 전체를 그대로 복사**해서 AI에게 주세요.
> "이 에러가 났어: [에러 전문 붙여넣기]. 왜 그런지 설명하고 고쳐줘."

### 법칙 5. 항상 "이게 최선이야?"를 묻는다
첫 결과물이 나오면 이렇게 물으세요:
> "이 코드에서 보안 문제나 버그 가능성이 있어? 더 단순하게 만들 수 있어?"

## 3장. 첫 작동하는 결과물 만들기 (실습)

목표: **30분 안에 인터넷에 올라간 진짜 웹페이지 1개.**

### Step 1 — 아이디어 한 줄 정하기
예: "BMI를 계산해주는 깔끔한 웹페이지"

### Step 2 — 마스터 프롬프트 던지기
아래를 그대로 AI에 붙여넣고 `[ ]` 부분만 바꾸세요:

```
너는 시니어 웹 개발자야. 아래 요구사항으로 완성된 단일 HTML 파일을 만들어줘.
별도 설명 없이 바로 브라우저에서 열면 작동해야 해.

- 기능: [BMI 계산기 — 키(cm)와 몸무게(kg)를 입력하면 BMI와 비만도 분류를 보여줌]
- 디자인: 모던하고 미니멀, 모바일 우선, 부드러운 색감
- 제약: 외부 라이브러리 없이 순수 HTML/CSS/JS, 단일 파일
- 추가: 결과가 나올 때 색으로 비만도를 구분해서 보여줘
```

### Step 3 — 저장하고 열어보기
AI가 준 코드를 `index.html` 로 저장 → 더블클릭 → 브라우저에서 확인.

### Step 4 — 마음에 들 때까지 다듬기
> "버튼 색을 좀 더 진하게, 그리고 결과 밑에 건강 팁 한 줄 추가해줘."

### Step 5 — 인터넷에 올리기 (배포)
`4장` 참고. GitHub Pages면 10분이면 됩니다.

---

## 4장. 무료로 배포하기 (GitHub Pages)

1. GitHub에서 새 저장소(repository)를 만든다. (Public)
2. `index.html` 파일을 업로드한다. ("Add file → Upload files")
3. 저장소 **Settings → Pages** 로 간다.
4. Source를 `main` 브랜치 `/ (root)` 로 설정하고 Save.
5. 1~2분 뒤 `https://[내아이디].github.io/[저장소명]/` 으로 접속 → 끝!

> 💡 이 키트에 들어있는 판매 페이지(`index.html`)도 정확히 이 방법으로 배포합니다.

## 5장. 만든 것으로 수익 내기

### 수익 모델 3가지 (난이도 순)

**① 디지털 상품 판매 (가장 빠름, 추천)**
- 가이드/템플릿/프롬프트 묶음을 Gumroad에 올린다.
- 마진 100%, 한 번 만들면 무한 판매.
- *이 키트 자체가 그 예시입니다.*

**② 마이크로 SaaS / 유료 도구**
- 특정 문제를 푸는 작은 웹도구를 만들고 구독/단건 결제.
- 예: 이미지 변환기, 견적 계산기, 콘텐츠 생성기.

**③ 외주 / 의뢰 제작**
- 바이브코딩으로 빠르게 만들어주고 제작비를 받는다.
- 랜딩페이지 1개 = 수십만 원.

### 첫 상품을 빠르게 검증하는 법
1. 만들기 **전에** 랜딩페이지부터 만들어 반응을 본다.
2. "사전 예약 / 대기자 등록" 버튼으로 수요 측정.
3. 관심이 모이면 그때 본 상품을 완성한다. (시간 낭비 0)

## 6장. 마인드셋 — 막히지 않는 법

- **완벽하게 이해하려 하지 마라.** 작동하면 된다. 이해는 따라온다.
- **AI를 동료로 대하라.** 모르면 물어보고, 틀리면 지적하라.
- **작게 출시하고 빨리 고쳐라.** 첫 버전은 부끄러운 게 정상이다.
- **매일 하나씩 만들어라.** 30일이면 당신은 완전히 다른 사람이다.
