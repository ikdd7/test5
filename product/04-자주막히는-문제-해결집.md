# 🛠️ 자주 막히는 문제 해결집

상황별로 그대로 복붙해서 AI에게 던지세요.

---

## 1. "AI가 준 코드가 작동을 안 해요"
```
방금 준 코드를 그대로 index.html로 저장해서 브라우저로 열었는데 [증상]이야.
빈 화면이거나 버튼이 안 눌려. 처음부터 끝까지 작동하는 완전한 단일 파일로
다시 줘. 외부 라이브러리 없이.
```

## 2. "에러 메시지가 떠요"
```
F12 개발자 도구 콘솔에 이런 에러가 떴어:
[에러 전문 붙여넣기]
무슨 뜻인지 쉽게 설명하고, 고친 전체 코드를 줘.
```

## 3. "모바일에서 깨져 보여요"
```
PC에선 괜찮은데 휴대폰에서 [글씨가 잘리고/버튼이 넘치고/레이아웃이 깨져].
모바일 우선으로 반응형 CSS를 점검하고 고친 전체 코드를 줘.
```

## 4. "GitHub Pages에 올렸는데 404가 떠요"
- 파일 이름이 정확히 `index.html` 인지 확인 (대소문자 주의)
- Settings → Pages에서 브랜치가 `main`, 폴더가 `/(root)` 인지 확인
- 배포 후 1~2분 기다리기 (즉시 안 됨)
- 그래도 안 되면:
```
GitHub Pages에 index.html을 올렸는데 404가 떠. 저장소는 Public이고
브랜치는 main이야. 체크해야 할 항목을 순서대로 알려줘.
```

## 5. "Gumroad 링크를 어디에 넣는지 모르겠어요"
- `index.html` 파일을 텍스트 에디터로 열기
- 맨 위쪽 `const GUMROAD_URL = "https://여기에-당신-링크"` 찾기
- 따옴표 안의 주소만 당신의 Gumroad 상품 URL로 교체
- 저장 후 다시 업로드

## 6. "디자인을 바꾸고 싶어요"
```
이 페이지의 [색상/폰트/버튼 모양/여백]을 [원하는 방향]으로 바꿔줘.
나머지는 그대로 두고 해당 부분만 수정한 전체 코드를 줘.
```

## 7. "AI가 자꾸 코드를 일부만 줘요"
```
중간에 생략하거나 '...' 으로 줄이지 말고, 복사해서 바로 쓸 수 있게
파일 전체를 처음부터 끝까지 완전하게 줘.
```

## 8. "뭘 만들지 모르겠어요"
```
나는 [내 관심사/직업/취미]에 관심 있어. 바이브코딩으로 하루 안에 만들 수 있고
사람들이 돈 낼 만한 작은 디지털 상품 아이디어 10개를 제안해줘.
각각 한 줄 설명과 예상 가격대도 같이.
```

## 9. "변경했는데 페이지에 반영이 안 돼요"
- 브라우저 강력 새로고침: `Ctrl+Shift+R` (Mac: `Cmd+Shift+R`)
- GitHub Pages는 반영까지 1~2분 걸릴 수 있음
- 파일을 실제로 다시 업로드(commit)했는지 확인

## 10. "더 잘 만들고 싶어요"
```
이 코드를 시니어 개발자 관점에서 리뷰해줘. 버그 가능성, 보안 문제,
더 단순하게 만들 부분을 짚고, 개선한 전체 코드를 줘.
```
