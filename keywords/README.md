# 🔑 계산기 키워드 후보 502개 + 실데이터 확보법

## ⚠️ 먼저 — 솔직한 한계
이 폴더의 **검색수요·경쟁 등급은 "추정치"** 입니다. 저(AI)는 실시간 키워드 데이터 API에 접속할 수 없어, 502개의 *정확한* 월간검색수·경쟁 페이지 수를 만들어내면 그건 허구가 됩니다. 그래서:
- **추정 등급**으로 502개를 가성비순 정렬해 드리고 (`keywords.csv`)
- **정확한 실제 숫자**는 아래 무료 도구로 5분 만에 뽑는 법을 안내합니다.

## 📂 파일
| 파일 | 내용 |
|------|------|
| `keywords.csv` | 502개 전체 (가성비점수 순). 컬럼: 키워드·카테고리·검색수요(추정)·경쟁(추정)·난이도·수익모델·점수 |
| `keywords-for-tool.txt` | 키워드만 줄단위. 키워드도구에 그대로 붙여넣기용 |
| `top-picks.md` | 가성비 TOP 40 |
| `generate.js` | 생성기 (카테고리·항목 추가/수정 가능) |

---

## ① 정확한 "월간 검색수" 뽑기 — 네이버 검색광고 키워드도구 (무료, 가장 정확)
1. [searchad.naver.com](https://searchad.naver.com) 가입(무료) → 로그인
2. **도구 → 키워드 도구** 진입
3. `keywords-for-tool.txt` 내용을 복사해 '키워드' 칸에 붙여넣기 (한 번에 최대 5개씩 또는 연관키워드 조회)
4. 결과에서 **월간검색수(PC/모바일)**, **경쟁정도(낮음/중간/높음)**, **월평균클릭수**, **클릭당 예상비용** 확인
   - 👉 *경쟁정도 '낮음' + 월간검색수 높음* = 노다지

> 팁: 모바일 검색수가 높은 키워드(건강·궁합·날짜·육아 등)는 공유훅과 궁합이 좋습니다.

## ② 정확한 "경쟁 페이지 수" 뽑기 — 구글 intitle 검색 (무료)
구글에서 아래처럼 검색하면 *제목에 키워드를 넣은 경쟁 페이지 수*가 대략 나옵니다:
```
intitle:"실업급여 계산기"
```
- 결과 상단의 "약 N개" 숫자가 경쟁 강도의 가늠자입니다.
- **N이 작고(예: 수천~수만)** 상위 노출이 개인 블로그/허접 사이트면 → 신규 진입 기회.
- N이 크고 상위가 네이버·토스·정부면 → 정면승부 회피(틈새로).

## ③ 키워드플래너 (구글 검색 비중용, 선택)
[ads.google.com](https://ads.google.com) → 도구 → 키워드 플래너 → 검색량 및 예측. 구글 검색 트래픽을 볼 때.

## 🎯 추천 워크플로 (최소 노력)
1. `top-picks.md`의 상위 키워드부터 ①②로 실제 숫자 검증
2. **수요 높음 × 경쟁 낮음** 5개를 추려 → 그중 1개를 계산기로 제작 (엔진/디자인은 이미 있음)
3. 제작 → 공유훅으로 커뮤니티 노출 → 반응 보고 다음 키워드로

## ➕ 키워드 더 만들기
`generate.js`의 `cat(...)` 블록에 항목을 추가하고 `node keywords/generate.js` 재실행하면 CSV가 갱신됩니다.
